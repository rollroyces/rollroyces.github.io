# rollroyces.github.io

Personal site for Royce — ML × bioinformatics engineer.

Hosted on GitHub Pages at <https://rollroyces.github.io>.

## Structure

- `_config.yml` — Jekyll config (minima theme, dark skin, author + social links)
- `index.md` — homepage content (about, featured work, open to roles, writing, contact)

## Local preview

```bash
bundle install
bundle exec jekyll serve
# → http://127.0.0.1:4000
```

## Updating

Edit `index.md` and push to `main`. GitHub Pages rebuilds automatically.
